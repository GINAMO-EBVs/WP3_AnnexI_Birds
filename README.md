# WP3_AnnexI_Birds
This repo contains the Rscript used for the GI assessment of a selection of 187 bird species. 
THIS README IS TO BE UPDATED
LAST UPDATE: 22/10/2026

# Metadata
The metadata used to assess the 187 bird species can be found in the excel file titled metadata.xlsx
The file has the right format to be compatible with the rscript (add name of file) used for the calculation and further analyses of the genetic indicators & correlation analysis. 

# Rscript; markdown format
The script can be used to redo the analyses of which the results are published in Mouton et al. (in review). It contains the script to calculate the species level genetic indicator values and the Ne500-species specific trait correlation analysis.
